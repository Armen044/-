# Кухня 5500 × 3000 (по эскизу заказчика)

Слева направо: пенал 950 под отдельностоящий холодильник 900 (без дна, боковины до пола) |
нижний ряд 3800 (450 · 600 ящики · 600 варочная · 600 · 600 ящики · 800 мойка · 150 карго) под столешницей на 900,
над ним верх 1050 + антресоль 450 (520 · 520 · 640 под вытяжку · 4 × 530) |
пенал-витрина 600 (стеклянные полки, LED по бокам, фасад алюминиевая рамка со стеклом) | пенал 150 с высоким карго.
Фасады МДФ 19 эмаль белая, ручка Gola.

- `kuhnya.pdf` — 2 листа А3: развёртка, план, разрез (1:20); 3D, модули, фасады, фурнитура.
- `kuhnya_3d.html` — 3D-модель одним файлом.

Пересборка: `python3 model.py && node render3d.js && python3 sheets.py && node render.js`
