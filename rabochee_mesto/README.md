# Рабочее место в детской 1370 × 600 × 2630

- `rabochee_mesto.pdf` — лист А3, 1:20: фасад, наполнение, разрез 1–1 через тумбу, план, примечания.
- `rabochee_mesto.png` — тот же лист картинкой.
- `rabochee_mesto_3d.html` — интерактивная 3D-модель, открывается без интернета:
  вращение, масштаб, открывание шкафов антресоли и ящиков тумбы.

Тумба: цоколь 80, ящики 210 / 211 / 211.

Пересборка:

```
python3 sheet.py               # лист (SVG)
node render.js                 # PNG + PDF
python3 build_interactive.py   # 3D: автономный HTML и версия для ссылки
node test_interactive.js       # проверка 3D (скриншоты)
```
