# Стол шлифовальный с нижней вытяжкой 2800 × 700

По фото стола в цеху и эскизу заказчика. Длина 2800, глубина 700, столешница на 900 (рабочая глубина 450),
перфостенка 550 над столом, открытый стеллаж 500 со светом. Камера-пустота для пылесоса под столешницей
и за перфостенкой, патрубки Ø160 сзади; внизу 3 выкатных ящика.

- `stol_shlif.pdf` — 2 листа А3: вид спереди, вид сверху, разрез А–А (1:10); 3D, детали для раскроя, фурнитура.
- `stol_3d.html` — интерактивная 3D-модель одним файлом (выдвижение ящика, снятие столешницы и перфостенки).

Пересборка:

```
python3 model.py      # детали, проверка пересечений, model.js
node render3d.js      # 3d_front.png, 3d_back.png, 3d_open.png
python3 sheets.py     # листы SVG
node render.js        # PNG + stol_shlif.pdf
```
