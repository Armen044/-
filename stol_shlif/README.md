# Стол шлифовальный с нижней вытяжкой 2800 × 700

По фото стола в цеху. Длина 2800, глубина 700, столешница на высоте 900, задняя стенка 550 над столом.

- `stol_shlif.pdf` — 2 листа А3: вид спереди, вид сверху, разрез А–А (1:10); 3D, детали для раскроя, фурнитура.
- `stol_3d.html` — интерактивная 3D-модель одним файлом (можно снять столешницу и лицевую панель).

Пересборка:

```
python3 model.py      # детали, проверка пересечений, model.js
node render3d.js      # 3d_front.png, 3d_back.png, 3d_open.png
python3 sheets.py     # листы SVG
node render.js        # PNG + stol_shlif.pdf
```
