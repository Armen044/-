# Участок 26.0 × 9.5 м — вариант 2: костровая зона справа

- `uchastok_list1.pdf/.png` — схема зонирования (А3, 1:80) с экспликацией; площади считаются из геометрии.
- `uchastok_list2.pdf/.png` — план рассадки декоративной зоны (А3, 1:50) с ассортиментом и количеством.

Изменения относительно исходной схемы: костровая площадка Ø 3.8 м перенесена вправо,
дорожка из плит идёт от террасы мимо костра (между костром и инжиром) к калитке огорода;
газон — по центру, слева цельный миксбордер; у костра хвойные заменены лавровишней,
вокруг площадки — кольцо очитка, злаки и хвойные не ближе 3 м от чаши.

Пересборка:

```
pip install shapely
python3 plants.py   # проверка посадок (налезание на дорожку/газон, расстояния до огня)
python3 draw.py     # SVG обоих листов
node render.js      # PNG + PDF
```

Геометрия зон — `geom.py`, позиции растений — `plants.py`.
