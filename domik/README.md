# Металлический каркас домика (труба 80×80)

По чертежу `domik_chertezh.pdf` (план 9400 × 6300 + блок 4000 × 7700, высота 3000).

- `domik_karkas.pdf` — 2 листа А3: план каркаса 1:50 с привязками стоек; 3D-виды, спецификация, раскрой на хлысты 12 м.
- `karkas_3d.html` — интерактивная 3D-модель одним файлом (вращение, масштаб, скрытие групп).

Правила каркаса: обвязки низ/верх по всем стенам и перегородкам, стойки в углах, на примыканиях,
у проёмов и промежуточные с шагом ≤ 2000 мм, перемычка над каждым проёмом, ригель под окнами.

Пересборка:

```
python3 model.py      # геометрия, проверка пересечений, model.js
node render3d.js      # 3d_sw.png, 3d_ne.png
python3 sheets.py     # листы SVG
node render.js        # PNG + domik_karkas.pdf
```
